:::info[Minecraft version compatibility]
Its 2026 and our plugins still support 1.8.8+ and java8! Thanks for all your feedback!

Still we strongly recommend to update your minecraft and java versions shortly as we are (like the spigot community) dropping support requests for 1.20 and lower versions. They will still remain but may not work in the future! May you would need a spigot fork to be compatible with a more recent version of java!
:::

:::warning[ALL PLUGINS NOW GOT THE MINIGAMES CORE]
We published the last missing plugin VD 5 Core Update to SPIGOTMC. Now all our plugins benefit from the minigames core improvements such as faster improvements and version support.
:::

**Throwback**

We started 2023 with the rollout on the BuildBattle, MurderMystery and TheBridge plugin. The updates worked well and over the time they got a lot of updates and improvements because of the Minigames Core. The Village Defense plugin needed a whole code base change because of the custom zombies generated by the plugin which got complicated since the change of the java versions and compiling at mojang.
So its finally nice to say, yeah, VD is also on the same code level and allows improvements sooner.

**Future Development**

Searching for development community which is providing new stuff into the plugins with e.g. Pull Requests on GitHub.
Currently its a one man development on its spare time. (You want to help, Write me fast, Now).

**Planned**
